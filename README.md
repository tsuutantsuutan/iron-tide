# 鋼鉄の海 IRON TIDE

ブラウザで遊べるリアル志向の艦隊戦ゲーム。インストール不要、リンクを開くだけで遊べる。

## モード
- **ストーリー「蒼の残光」** 全5話。戦艦「大和」の艦長として戦う架空戦記
- **チュートリアル** 操作を一通り練習
- **フリーミッション** 海域・天候・海況・敵味方編成・難易度を自由に設定
- **マルチプレイ**（最大8人。ルームを作って招待リンクを送るだけ）
  - 対戦（個人戦）／チーム戦（最大4対4、空き枠はNPC）／協力ボス戦（難易度4段階）

## 操作
| 操作 | キー |
|---|---|
| 照準 | マウス（画面クリックで固定、Escで解除） |
| 照準器（双眼鏡） | 右クリック / Shift 長押し（ホイールで ×2〜×16） |
| 斉射 | 左クリック |
| 速力（後進〜最大戦速） | W / S |
| 舵（取舵・面舵） | A / D |
| 徹甲弾 / 榴弾 | 1 / 2 |
| 魚雷モード | T（駆逐艦・重巡） |
| 応急修理 | R |
| 地図 / 戦況 / 砲弾視点 | M / Tab / V |

## リアルさのポイント
- 艦の寸法・速力・主砲口径・砲弾重量・初速は実艦データ（大和 263m・27kt・46cm砲 1,460kg・初速780m/s など）
- 砲弾は重力＋空気抵抗で飛ぶ。着弾まで10秒以上かかるので未来位置を狙う
- 装甲貫通（舷側・甲板・入射角）・跳弾・過貫通・重要区画（バイタル）・火災・浸水・弾薬庫誘爆
- 発砲音は音速で届く（遠くの敵の発砲炎が見えてから数十秒後に音が聞こえる）
- ゲルストナー波の海、航跡（ケルビン波）、浅瀬の色、岸の白波、軍港・防波堤・灯台

## 構成
`index.html` と `js/` だけの静的サイト（Three.js r128）。通信は公開MQTTブローカー（WebSocket）経由のリレー。
